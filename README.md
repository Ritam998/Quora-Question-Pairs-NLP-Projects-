# Quora Question Pairs — NLP Project

## About the Project

This project explores **Natural Language Processing (NLP)** to determine whether two questions have the same meaning, even when they are written differently.

For example:

* Question 1: *How can I learn Python?*
* Question 2: *What is the best way to learn Python?*

The goal is to identify semantically similar questions using text preprocessing and machine learning techniques.

## Dataset

This project uses the [Quora Question Pairs Dataset](https://www.kaggle.com/c/quora-question-pairs), available on Kaggle.

The dataset contains pairs of questions labelled according to whether they are duplicates.
